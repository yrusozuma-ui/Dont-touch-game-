DON'T TOUCH — Juego web arcade

ARCHIVOS
- index.html: juego completo. No necesita instalar librerías ni servidor.

PROBAR EN EL CELULAR
1. Descarga index.html.
2. Ábrelo con un editor de HTML o súbelo directamente a GitHub siguiendo las instrucciones.
3. Para publicarlo, GitHub Pages necesita que index.html esté en la raíz del repositorio.

PUBLICAR CON GITHUB PAGES
1. Crea/inicia sesión en https://github.com/
2. Crea un repositorio público llamado dont-touch-game.
3. Pulsa Add file > Create new file.
4. Escribe index.html como nombre y pega el contenido del archivo.
5. Guarda con Commit changes.
6. En Settings > Pages, elige Deploy from a branch, rama main, carpeta /(root), y Save.
7. Espera unos minutos. La URL será https://TU-USUARIO.github.io/dont-touch-game/
   (reemplaza TU-USUARIO por tu usuario de GitHub).

El repositorio público y el sitio publicado son visibles para cualquiera. No subas contraseñas, dirección, teléfono ni datos personales.
